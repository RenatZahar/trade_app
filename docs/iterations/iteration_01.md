## Краткие напоминания

### argparse

База по argparse:

Создаешь парсер:

```python
parser = argparse.ArgumentParser(description="Unified entrypoint")
```

Добавляешь аргументы:

```python
parser.add_argument("--start-parser", action="store_true")
parser.add_argument("--mode", choices=["train", "serve", "update_data"])
```

Получаешь объект `Namespace`:

```python
args = parser.parse_args()
```

Читаешь значения:

```python
if args.start_parser:
    ...
if args.mode == "train":
    ...
```

Что важно понять:

- `action="store_true"` значит булев флаг: если передан, будет `True`, иначе `False`.
- Если аргумент не объявлен через `add_argument`, у `args` его не будет.
- `choices=[...]` полезен, чтобы ограничить допустимые значения и получить ошибку сразу на уровне CLI.
- `-h/--help` создается автоматически и показывает описание и список аргументов.
